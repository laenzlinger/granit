Overview

Custom carrier board for the Raspberry Pi CM4 Compute Module, designed as a minimal offsite backup appliance.

A compact, headless device that connects to a remote network and receives encrypted backups onto an attached hard disk. Designed to be left at a trusted offsite location and managed remotely.
